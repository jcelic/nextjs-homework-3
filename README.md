# Task App

Jednostavna Next.js Todo aplikacija.

## Tehnologije

- Next.js
- TypeScript
- Tailwind CSS
- TanStack Query
- Zustand
- MockAPI

## Funkcionalnosti

- dohvat zadataka s API-ja
- dodavanje i uređivanje zadataka
- označavanje zadataka kao dovršenih
- optimistic update za dodavanje zadataka
- light/dark tema pomoću Zustanda
